# ClubVerse — ระบบจัดการชมรม

เว็บไซต์สำหรับจัดการข้อมูลชมรม สมาชิก และกิจกรรมภายในมหาวิทยาลัย ผู้ใช้สามารถค้นหาชมรม สมัครหรือออกจากชมรม ลงทะเบียนหรือยกเลิกกิจกรรม และแก้ไขข้อมูลโปรไฟล์ได้ผ่านเว็บไซต์

## 1. สมาชิกและบทบาทผู้ใช้

- **Admin (ผู้ดูแลระบบ):** ดูรายชื่อบัญชีผู้ใช้ กำหนดบทบาทผู้ใช้ เพิ่มและลบชมรม และจัดการกิจกรรมได้ทุกชมรม รวมถึงดูรายชื่อสมาชิกและนำสมาชิกออกจากชมรมได้ทุกชมรม
- **Student (นักศึกษา):** สมัครสมาชิก เข้าสู่ระบบ ดูและค้นหาชมรม สมัครเข้าชมรมหรือออกจากชมรม ลงทะเบียนหรือยกเลิกกิจกรรม และแก้ไขโปรไฟล์ของตนเอง
- **Club Staff (ผู้ดูแลชมรม):** จัดการกิจกรรมและสมาชิกของชมรมที่ Admin มอบหมายให้เท่านั้น สามารถเพิ่ม แก้ไข และลบกิจกรรม รวมถึงนำสมาชิกออกจากชมรมที่รับผิดชอบได้

การนำสมาชิกออกจากชมรมจะยกเลิกเฉพาะสมาชิกภาพของชมรมนั้น ไม่ได้ลบบัญชีผู้ใช้ออกจากระบบ

## 2. วัตถุประสงค์

พัฒนาเว็บไซต์สำหรับจัดการข้อมูลชมรม สมาชิก และกิจกรรมภายในมหาวิทยาลัย เพื่อให้ผู้ใช้สามารถค้นหาข้อมูลชมรม สมัครหรือออกจากชมรม ลงทะเบียนหรือยกเลิกกิจกรรม และจัดการข้อมูลโปรไฟล์ได้สะดวกผ่านเว็บไซต์

## 3. Features

- สมัครสมาชิก เข้าสู่ระบบ และออกจากระบบ
- แสดงรายการชมรม ค้นหาชมรม และดูรายละเอียดชมรม
- สมัครเข้าชมรมและออกจากชมรม
- จำกัดสมาชิกหนึ่งคนให้สังกัดได้เพียงหนึ่งชมรมในเวลาเดียวกัน
- แสดงรายการกิจกรรมและรายละเอียดกิจกรรม
- ลงทะเบียนและยกเลิกการลงทะเบียนกิจกรรม
- ดูและแก้ไขข้อมูลโปรไฟล์ รวมถึงเปลี่ยนรหัสผ่าน
- แสดงบทบาทผู้ใช้ ได้แก่ Student, Club Staff และ Admin
- มีเมนูสามขีด ปุ่มย้อนกลับ และปุ่มแสดง/ซ่อนรหัสผ่าน
- Admin ดูรายชื่อผู้ใช้และกำหนดบทบาทได้
- Admin กำหนดชมรมที่รับผิดชอบให้บัญชี Club Staff ได้
- Admin เพิ่มและลบชมรมได้
- Admin จัดการกิจกรรมและสมาชิกได้ทุกชมรม
- Club Staff เพิ่ม แก้ไข และลบกิจกรรมได้เฉพาะชมรมที่ได้รับมอบหมาย
- Club Staff ดูรายชื่อสมาชิกและนำสมาชิกออกจากชมรมที่ได้รับมอบหมายได้
- ตรวจสอบสิทธิ์การจัดการข้อมูลฝั่งเซิร์ฟเวอร์ด้วยบทบาทและชมรมที่ได้รับมอบหมาย

## 4. Technologies

- **HTML5** — สร้างโครงสร้างหน้าเว็บ
- **CSS3** — ตกแต่งและจัดรูปแบบหน้าเว็บ
- **JavaScript** — ควบคุมการทำงานของหน้าเว็บ
- **DOM Manipulation** — จัดการองค์ประกอบและการโต้ตอบบนหน้าเว็บ
- **Node.js** — รันโปรแกรมฝั่งเซิร์ฟเวอร์
- **Express.js** — จัดการ Routes และ HTTP Request/Response
- **MongoDB** — จัดเก็บข้อมูลผู้ใช้ ชมรม สมาชิก และกิจกรรม
- **Mongoose** — เชื่อมต่อและจัดการข้อมูล MongoDB
- **express-session** — จัดการสถานะการเข้าสู่ระบบ
- **Cookies** — เก็บ Session ID ตามการตั้งค่า Session ของระบบ
- **bcryptjs** — แฮชรหัสผ่านก่อนจัดเก็บในฐานข้อมูล

## 5. สิ่งที่ต้องติดตั้งก่อนใช้งาน

1. ติดตั้ง [Node.js](https://nodejs.org/)
2. ติดตั้งและเปิดใช้งาน MongoDB ในเครื่อง หรือเตรียม MongoDB URI ที่เชื่อมต่อได้
3. ติดตั้ง Visual Studio Code (แนะนำ)

## 6. วิธีติดตั้ง

1. เปิดโฟลเดอร์โปรเจกต์ที่มี `package.json` ด้วย Visual Studio Code
3. เปิด Terminal ในโฟลเดอร์โปรเจกต์
4. ติดตั้ง Dependencies ด้วยคำสั่ง

```bash
npm install
```

5. คัดลอกไฟล์ `.env.example` เป็น `.env`
6. ตรวจสอบค่าภายใน `.env` ให้ตรงกับเครื่องของคุณ ตัวอย่างค่าตั้งต้น:

```env
PORT=3000
MONGODB_URI=mongodb://127.0.0.1:27017/club_management
SESSION_SECRET=change-this-secret-before-deployment
ADMIN_USERNAME=Toon
ADMIN_PASSWORD=1234
```

หากเปลี่ยนชื่อฐานข้อมูลหรือข้อมูลบัญชี Admin ใน `.env` ให้ใช้ค่าที่ตั้งไว้จริงในไฟล์นั้น

## 7. วิธี Run

เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:

```bash
npm start
```

จากนั้นเปิดเว็บเบราว์เซอร์และเข้าไปที่:

http://localhost:3000

หากเชื่อมต่อ MongoDB ไม่ได้ ให้ตรวจสอบว่า MongoDB กำลังทำงานอยู่ และค่า `MONGODB_URI` ใน `.env` ถูกต้อง

## 9. วิธีตั้งค่าบัญชีผู้ดูแลชมรม

1. สมัครบัญชีผู้ใช้ตามปกติ หรือใช้บัญชีที่มีอยู่แล้ว
2. เข้าสู่ระบบด้วยบัญชี Admin
3. เปิดเมนู **จัดการระบบ**
4. ในตารางบัญชีผู้ใช้ เลือกบทบาท **ผู้ดูแลชมรม (Club Staff)** ให้บัญชีที่ต้องการ
5. เลือกชมรมที่ต้องการมอบหมายให้บัญชีนั้น
6. กด **บันทึก**
7. ให้บัญชีผู้ดูแลชมรมออกจากระบบและเข้าสู่ระบบใหม่
8. เปิดเมนู **จัดการชมรม** เพื่อดูสมาชิกและจัดการกิจกรรมของชมรมที่ได้รับมอบหมาย

หากยังไม่ได้มอบหมายชมรม บัญชี Club Staff จะยังไม่มีชมรมให้จัดการ
